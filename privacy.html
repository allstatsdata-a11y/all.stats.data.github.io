Какие данные мы получаем

С разрешения владельца или менеджера канала приложение LSN Stats получает через официальные YouTube Data API и YouTube Analytics API статистику канала: название и аватар канала, число подписчиков, просмотров, лайков и комментариев, данные об аудитории (возраст, пол, страны, устройства — только в обобщённом виде, без сведений о конкретных зрителях), а также даты публикации роликов. Доступ предоставляется только на чтение (области доступа youtube.readonly и yt-analytics.readonly).

Как мы используем данные

Данные используются исключительно для отображения статистики на внутреннем сайте организации. Приложение ничего не публикует, не изменяет и не удаляет на каналах.

Хранение и передача

Данные хранятся на сервере организации в локальной сети и не передаются третьим лицам, не продаются и не используются для рекламы. Использование и передача информации, полученной из API Google, соответствуют Google API Services User Data Policy, включая требования об ограниченном использовании (Limited Use).

Отзыв доступа

Владелец канала может в любой момент отозвать доступ на странице myaccount.google.com/permissions. По запросу на адрес ниже собранные данные канала будут удалены.

Privacy Policy

Last updated: October 10, 2026

Data we access

With the permission of a channel owner or manager, LSN Stats uses the official YouTube Data API and YouTube Analytics API to read channel statistics: channel title and avatar, subscriber, view, like and comment counts, aggregated audience data (age, gender, countries, devices — no information about individual viewers) and video publish dates. Access is read-only (youtube.readonly and yt-analytics.readonly scopes).

How we use data

Data is used solely to display statistics on the organization's internal dashboard. The app never publishes, modifies or deletes anything on the channels.

Storage and sharing

Data is stored on the organization's server inside its local network. It is not shared with third parties, sold, or used for advertising. LSN Stats' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

A channel owner can revoke access at any time at myaccount.google.com/permissions. On request to the address below, the collected channel data will be deleted.
